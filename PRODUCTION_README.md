# 🚀 Руководство по запуску в ПРОДАКШЕН

## ⚠️ ВАЖНО: Что нужно сделать ПЕРЕД запуском

### ШАГ 1: Сгенерировать секретный ключ

Запустите в терминале:

```bash
./generate_secret.sh
```

Скрипт либо сам добавит ключ в `.env`, либо покажет его для копирования.

### ШАГ 2: Проверить и отредактировать файл `.env`

Откройте файл `.env` (находится в корне проекта) и проверьте эти строки:

| Что                     | Где найти | Пример                                                   |
| ----------------------- | --------- | -------------------------------------------------------- |
| **NEXT_PUBLIC_API_URL** | строка 2  | `http://backend:8000` (оставить как есть)                |
| **DB_USER**             | строка 5  | `arseny` (пользователь БД)                               |
| **DB_PASSWORD**         | строка 6  | `Scrab173War!` (измените на свой пароль!)                |
| **DB_NAME**             | строка 7  | `music_app` (оставить как есть)                          |
| **DATABASE_URL**        | строка 8  | **ВАЖНО**: пароль должен быть ТАКИМ ЖЕ как `DB_PASSWORD` |
| **SECRET_KEY**          | строка 11 | Сгенерирован на ШАГЕ 1                                   |
| **ENVIRONMENT**         | строка 14 | `production` (для продакшена)                            |
| **DEBUG**               | строка 15 | `false` (для безопасности)                               |

**Пример правильного `.env`:**

```bash
NEXT_PUBLIC_API_URL=http://backend:8000
DB_USER=arseny
DB_PASSWORD=ваш_сложный_пароль
DB_NAME=music_app
DATABASE_URL=postgresql://arseny:ваш_сложный_пароль@db:5432/music_app
SECRET_KEY=ваш_длинный_ключ_от_скрипта
ENVIRONMENT=production
DEBUG=false
```

⚠️ **Самая частая ошибка**: `DB_PASSWORD` и пароль в `DATABASE_URL` должны совпадать!

### ШАГ 3: Отредактировать `backend/app/core/config.py`

Откройте файл `backend/app/core/config.py` и найдите строку:

```python
ALLOWED_ORIGINS: list[str] = ["http://localhost:3000", "http://127.0.0.1:3000"]
```

Замените на ваш домен:

```python
ALLOWED_ORIGINS: list[str] = [
    "https://ваш-домен.com",
    "https://www.ваш-домен.com"
]
```

**Например, если у вас домен `music.example.com`:**

```python
ALLOWED_ORIGINS: list[str] = [
    "https://music.example.com",
    "https://www.music.example.com"
]
```

## 🏥 Проверки здоровья (Health Checks)

Приложение имеет встроенные проверки:

- **Backend**: `GET /health` - проверка работоспособности API
- **База данных**: автоматическая проверка PostgreSQL
- **Frontend**: проверка доступности сайта

## 🔒 Безопасность

### Что уже настроено:

- ✅ CORS только для указанных доменов
- ✅ Секретный ключ через переменные окружения
- ✅ Пароль базы данных через переменные окружения
- ✅ HTTPS принудительно в продакшене

### Дополнительные меры безопасности:

1. **SSL сертификат**: Получите бесплатный от Let's Encrypt
2. **Firewall**: Откройте только порты 80, 443, 22
3. **Бэкапы**: Настройте автоматическое резервное копирование базы данных

## 🚀 Запуск в продакшен

### Вариант 1: Docker (рекомендуется)

```bash
# В корне проекта
docker-compose up --build -d
```

### Вариант 2: На сервере без Docker

```bash
# Установите PostgreSQL
sudo apt install postgresql

# Создайте базу данных
createdb music_app

# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 📊 Мониторинг

### Что отслеживать:

- **Логи**: `app.log` - ошибки и события
- **Health checks**: Все сервисы должны быть "healthy"
- **База данных**: Свободное место и соединения
- **Диск**: Место для музыки и обложек

### Инструменты для мониторинга:

- **Grafana + Prometheus**: Для метрик
- **Sentry**: Для ошибок в коде
- **UptimeRobot**: Для проверки доступности

## 🔧 Устранение проблем

### Если не запускается:

1. Проверьте логи: `docker-compose logs`
2. Проверьте переменные: `cat .env`
3. Проверьте порты: `netstat -tlnp`

### Если база данных не подключается:

1. Проверьте пароль в `.env`
2. Проверьте `DATABASE_URL` в `.env`
3. Проверьте логи PostgreSQL

### Если CORS ошибки:

1. Проверьте `ALLOWED_ORIGINS` в `config.py`
2. Убедитесь, что домен указан с `https://`

## 📞 Поддержка

Если что-то не работает:

1. Проверьте логи всех сервисов
2. Убедитесь, что все переменные окружения указаны
3. Проверьте, что порты 8000 и 3000 свободны
